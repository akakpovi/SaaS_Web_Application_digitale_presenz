## 🧪 Guide de Test Rapide des Nouveaux Endpoints

Tous vos conteneurs tournent. Vous pouvez tester directement les nouveaux endpoints via `curl` ou votre outil d'API (Postman / Swagger) :

### 1. 💬 Tester l'Analyse de Sentiment IA d'un Avis
```bash
# Déclencher l'analyse NLP asynchrone d'un avis
curl -X POST http://localhost:8000/api/v1/reviews/<VOTRE_REVIEW_UUID>/analyze-sentiment/ \
     -H "Authorization: Bearer <VOTRE_TOKEN_JWT>"
```

### 2. 📥 Importer des Avis en Masse (CSV ou JSON)
```bash
curl -X POST http://localhost:8000/api/v1/reviews/import/ \
     -H "Authorization: Bearer <VOTRE_TOKEN_JWT>" \
     -F "source_id=1" \
     -F "file_type=csv" \
     -F "file=@mes_avis.csv"
```

### 3. 🔍 Lancer un Audit SEO Technique
```bash
curl -X POST http://localhost:8000/api/v1/websites/<ID_SITE>/seo/audits/run/ \
     -H "Authorization: Bearer <VOTRE_TOKEN_JWT>"
```

### 4. 🛡️ Lancer un Scan de Sécurité Réseau & Malware
```bash
curl -X POST http://localhost:8000/api/v1/websites/<ID_SITE>/security/scan/ \
     -H "Authorization: Bearer <VOTRE_TOKEN_JWT>"
```

### 5. 📱 Synchroniser l'Engagement Social & Détecter les Mentions
```bash
curl -X POST http://localhost:8000/api/v1/websites/<ID_SITE>/social/sync/ \
     -H "Authorization: Bearer <VOTRE_TOKEN_JWT>"
```
